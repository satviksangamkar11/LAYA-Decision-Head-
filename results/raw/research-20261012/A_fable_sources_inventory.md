# A. Fable 5 source inventory (metadata only), checked 2026-10-12

Scope: 19 public Hugging Face dataset repos that claim to contain "Fable 5" coding-agent sessions, plus `cfahlgren1/Fable-5-traces` as a cited origin.
Method: `huggingface.co/api/datasets/<repo>` (with `?blobs=true` for file sizes), `datasets-server` `/size`, `/info`, `/splits`, `/first-rows` (10 to 16 rows per repo), and the raw dataset card (`README.md`). No dataset files were downloaded. Raw responses are in the scratchpad (`meta/`), not in the project.

Duplicate tests: LFS sha256 and git blob ids of listed files (files above 10 KB or 1 MB, as noted), plus shared session UUID filenames. "Claim" means the uploader's card text. It is not verified.

Limits found while checking:
- datasets-server cut long cells at exactly 100 characters for `messages`, `trace`, `metadata` and `tools` in 11-47, TeichAI, AlinCiocan, armand0e, Swarm and one Tradefederation row. `truncated_cells` was empty in every response. Tool results inside those cells could not be seen, so they are marked "not verified".
- `lastModified` is the last change date, not the creation date. Used only as a tie-breaker, and marked as such.

## 2. Ranked: most promising ORIGINAL sources for new tool-using sessions

Ranking is among repos where no duplicate was found in the checked set. Originality is not proven against unlisted sources (Glint-Research, greghavens and cfahlgren1 were not accessible or not analysed).

1. **AlinCiocan/fable-5-claude-code-traces** (cc-by-4.0). One row per Claude Code session with the full event stream and per-session tool-call counts (5 to 118 in the sample). No overlap found with other repos. Risks: only 18 sessions; the card says the data is scrubbed; the Fable model identity is not decoded; tool-result content was not read.
2. **armand0e/claude-fable-5-claude-code** (mit). 63 sessions, `num_tool_calls` 0 to 147 in the sample (9 of 10 sessions above 0). Risks: 29 of its session UUIDs also appear in the 1EYE4ALL, Tradefederation and c777777 set, with different content; the card claims it is the same data as Glint-Research (not accessible); the model field and results were not decoded. Dedupe against the 1EYE4ALL set before use.
3. **The 79-session raw Claude Code core** (claude/projects in 1EYE4ALL, Tradefederation and c777777). The largest raw session set found (79 UUIDs). Risks: the same files appear in three repos, so the origin is unclear; the schema is heterogeneous (datasets-server CastError), so a custom parser is needed; row count and tool results are not verified.
4. **11-47/Fable-5-Cursor-Traces** (apache-2.0; identical to TeichAI). 244 Cursor sessions with tool schemas, a different harness from the others, and a permissive license. Risks: tool calls and results were not visible in first rows (cell cut at 100 characters); "Fable 5" is only a system-prompt claim; the Enderchef attribution was not checked.
5. **Tradefederation/Fable-5-traces pi_agent folder** (identical to c777777). Pi-agent format with toolCall events (6 of 9 sampled traces). Risks: no tool results in the 9 sampled traces; the card says 60 source sessions but 4,665 rows; this is a copy, not a new source.

Not ranked: DSFFGFG456 (already held). Its tool calls and results are verified in the sample (best evidence in this set), but `model_attested` is false and `teacher_model` is empty in all 16 sampled rows, so the Fable 5 claim is unsupported.

- 1EYE4ALL/Fable-5-traces row count and format: first-rows CastError (500); size endpoint returned 0 rows.
- LanguaMan/fable-5-sft-traces row count, tool calls and model field: datasets-server cannot read the parquet (404 from storage).
- c777777/Fable-5-traces row count: size endpoint returned 0 rows. Inferred only from the identical file tree with Tradefederation.
- Tool results: not verified for 11-47, TeichAI, AlinCiocan, armand0e, Swarm, and Crownelius (cells cut at 100 characters). Not decodable without downloading, which was not allowed. Tool results were not found in the 9 sampled pi traces (Tradefederation/c777777).
- Model identity: not verified for any repo. The only model fields seen are uploader-set (kelexine sft, kelexine/Jrmyrion, and `source` in lordx64). DSFFGFG456 has `model_attested` false in all sampled rows.

- Which copy of each duplicate group is the original: only lastModified dates are available, and they are not creation dates. Earliest lastModified: kelexine/Fable-5-traces (over Jrmyrion); 11-47 (over TeichAI); c777777 (over Tradefederation).

- Swarm's 18 Claude Code sessions vs AlinCiocan's 18: not matched (Swarm's file names are not session UUIDs).
- Kelexine capitalisation: the list name redirects to the lowercase repo; datasets-server still says "renamed". The lowercase name was used.
