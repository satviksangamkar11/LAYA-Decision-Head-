## Findings that change the plan
- **The Java kit's own grader depended on the host locale:** the reference for J1-09 failed in a clean jail until UTF-8 was set explicitly (fixed in the jailed grader).
- **Process limits need an unprivileged user:** run as root inside a user namespace, the fork limit did not apply (200 forks succeeded). The grader now runs the jail as `nobody`; the fork test stops at 30.
- **Python mutation:** two tasks (P1-19, P1-26) are below 0.80 raw; all their survivors are likely equivalent. Three tasks (P1-05, 10, 14) have no mutation score; their 9 hand-written wrong solutions are all caught.
- **Java mutation:** J1-08 and J1-10 are inline library calls with nothing to mutate, and J1-20 produced no valid mutant; all three stay unmeasured. J1-17 and J1-27 are below 0.80 raw with only likely-equivalent survivors.
- "Likely equivalent" means: no distinguishing input in 3,000 to 20,000 random valid inputs. It is evidence, not proof.
