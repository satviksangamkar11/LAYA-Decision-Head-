## Files (all new, mine)
- `evidence_ladder/bank40.py` shared model-free logic: **thinking policy** (`check_policy`: `budget` | `prompt_brief` | `model_variant`; missing/unknown/malformed -> refused, nothing hard-coded), deterministic disjoint sharding, time guard, resume markers, Timeline + TimedGen/TimedExec, RecordingGen/SequenceReplayGen (pass 2 regenerates nothing), BriefPromptGen (ceiling hits counted as FAILED generations), public-only bundle guard, verdict helpers.

## How it runs
- **pass 1 (GPU, T4 x2, internet off, no secrets):** verify bundle hashes -> require `thinking_policy` from the bundle's run_config.json (else `REFUSED_NO_THINKING_POLICY`) -> public-only guard on every mounted file (`REFUSED_BUNDLE_NOT_PUBLIC`) -> `EL_JAIL=kaggle`, build rootfs (system JDK), self-check in the jail (python runs, javac runs, socket() denied, host canary unreadable, bwrap swapped for the Kaggle jail); **any failure = `JAIL_UNAVAILABLE`, nothing executed, no unsandboxed fallback** -> verify model sha256 -> shard 20/20 over the visible GPUs, one worker process per GPU (`CUDA_VISIBLE_DEVICES`), nvidia-smi sampled every 30 s -> each task through `EvidenceLadderController` (ladder mode; investigate, k=4 candidates, public examples, L2 (6), L1 clustering, discrimination via the blinded critic hand-off, rank, repair, verify), `scorer=None` (recorded `scorer: none`), `ControllerContext(gen, exe=SandboxExecutionBackend, TokenBudget cap 100000, ..., critic=StagedCriticBroker)`; I8 deep scan of the live context before each task.
- Per finished task, atomically: result.json, journal.jsonl, gen_calls.json (every generation in order), critic_requests.json, controller_timeline.json (Agent 2's Timeline), glm/ ledger, and **DONE last**. Time guard (default 11 h of 12, `EL_GUARD_H`) stops starting tasks and records them pending; a re-run with the previous output mounted skips every task with DONE and retries tasks without it.
- At the end: TIMELINE.jsonl (+ per-worker files), TIMELINE_SUMMARY.json, gpu_util.jsonl, critic_packets/ (blinded, validated by critic_batch/validator.py), RUN_SUMMARY.json (policy, jail receipt, model sha, shards, resumed/pending, always exit 0).
- **pass 2 (CPU, jail on):** mounts pass-1 output + critic responses; for each task with pending packets replays the recorded generations in order (purpose/n/seeds/prompt-hash checked; a difference raises, nothing is regenerated) and applies the critic responses.
- Timestamps: real UTC (ms) for kernel start, bundle verify, rootfs build, model sha, model load, GPU name, every generate / sandbox_public / sandbox_experiment call, task start/end, critic export, kernel end; plus the controller's stage timeline per task.

## Thinking policy (pending the user's choice)
One explicit setting in the packer: `--thinking-policy budget --think-budget N --answer-tokens M` | `prompt_brief --brief "<one line>" --ceiling N` | `model_variant --profile-id ID --model-glob FRAGMENT --ceiling N`. No default; copied into RUN_SUMMARY, every result and the results header. `prompt_brief` appends the one-line instruction to the prompt (replay hashes use the original prompt), caps total new tokens only at the technical ceiling, and a generation that hits it is a `ceiling_hit` event and counts as FAILED (`generation_failed_at_ceiling`), never success. `model_variant` needs a backbone profile with enable_thinking False in configs/backbones_v1.toml (not present today: add it first, otherwise the kernel cannot build the backend).

## Runtime estimate (unmeasured)
`estimate (unmeasured)`: a T4 fp16 4B generates roughly 20-30 tokens/s one sequence at a time (HFQwenBackend), so one capped sequence (think + answer, up to ~2000 tokens) takes about 1-2 minutes; a ladder task needs about 10-20 sequences (4 candidates + L2 tests per round, up to 2 rounds) plus sandbox runs (seconds each, Java compiles longer) -> about 15-40 minutes per task, 20 tasks per GPU -> roughly 5-13 hours of wall time. Expect the 11 h guard to be reachable: plan for one resume version. `prompt_brief` / `model_variant` change this strongly (unbounded thinking inside the ceiling is slower; a non-thinking model is much faster). Measure with the first run; the timeline will show it.
